# Sprint 06 - Media & Operations

هدف: تکمیل رسانه، hardening امنیتی و ابزارهای عملیاتی توسعه.

## Epic 12 - فایل، تصویر و رسانه

### PBI-12-01 - آپلود تصویر محصول، بنر و آواتار

به عنوان ادمین، می‌خواهم تصویر را آپلود کنم تا وابسته به URL خارجی نباشیم.

معیار پذیرش:

- `POST /api/v1/media/upload` تصویر را دریافت و URL پایدار برگرداند.
- نوع فایل و حجم validate شود.
- تصاویر محصول، بنر، logo و avatar از یک سرویس مشترک استفاده کنند.
- امکان استفاده از storage محلی در dev و S3-compatible storage در production وجود داشته باشد.

اولویت: Could

## Epic 13 - مشاهده‌پذیری، امنیت و عملیات

### PBI-13-02 - محدودسازی نرخ و hardening امنیتی

به عنوان مالک سیستم، می‌خواهم endpointهای حساس در برابر سوءاستفاده محافظت شوند.

معیار پذیرش:

- rate limit برای login و refresh token وجود داشته باشد.
- headerهای امنیتی پایه اضافه شوند.
- CORS در production محدود به دامنه‌های مجاز باشد.

اولویت: Should

### PBI-13-03 - seed و reset داده توسعه

به عنوان توسعه‌دهنده، می‌خواهم داده نمونه معنادار داشته باشم.

معیار پذیرش:

- command مستقل برای seed داده توسعه وجود داشته باشد.
- reset mock فقط در محیط dev فعال باشد.
- داده seed با موجودیت‌های frontend فعلی سازگار باشد.

اولویت: Could
